# SOC Analysis Projects

## About This Repository

Welcome to my SOC Analysis Projects repository.

This repository contains the hands-on projects I have completed while learning and practicing SOC Analyst skills. Each project is based on real investigation techniques and focuses on understanding security events, identifying suspicious activity, and documenting the findings in a clear and organized way.

The purpose of this repository is to improve my practical knowledge, build a strong cybersecurity portfolio, and track my learning as I prepare for a SOC Analyst L1 role.

---

## Project Categories

The projects in this repository include:

- Phishing Email Analysis
- Network Traffic Analysis
- Malware Analysis
- Windows Event Log Analysis
- Windows Process Investigation
- Windows Service Investigation
- Windows Registry Analysis
- Sysmon Log Analysis
- Threat Hunting
- Incident Response
- Splunk and SIEM Investigations
